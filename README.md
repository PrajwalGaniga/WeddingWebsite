# WeddingWebsite

Luxury, mobile-first interactive digital wedding invitation web application for Neslin & Gaywin.

## Features
- **Cinematic Envelope Opening**: 3D interactive envelope intro with wax seal crack, flap unfold, card reveal, and canvas petal burst.
- **Synced Background Audio**: Unmuted on user gesture with floating interactive sound equalizer control.
- **Royal Heritage Aesthetics**: Tailored terracotta, ivory parchment, gold accents, and floral motifs.
- **Event Itinerary**: Frosted glassmorphism event cards for Roce Ceremony, Nuptial Mass, and Wedding Reception with direct Google Maps and Add to Calendar integrations.
- **Interactive Details**: Live countdown timer, December 2026 calendar highlight, scripture, and personalized guest greeting support (`?guest=Name`).

## Tech Stack
- **Framework**: Next.js (App Router, Turbopack)
- **Styling**: Tailwind CSS & CSS 3D transforms
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
